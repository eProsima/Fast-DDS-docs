# DataSharingKind

### enum eprosima::fastdds::dds::DataSharingKind

Data sharing configuration kinds 

*Values:*

### enumerator AUTO

Automatic configuration. DataSharing will be used if requirements are met. 

### enumerator ON

Activate the use of DataSharing. [Entity](../entity.md#classeprosima_1_1fastdds_1_1dds_1_1Entity) creation will fail if requirements for DataSharing are not met 

### enumerator OFF

Disable the use of DataSharing
