# IsAddressDefined

### inline bool eprosima::fastdds::rtps::IsAddressDefined(const [Locator_t](Locator_t.md#_CPPv4N8eprosima7fastdds4rtps9Locator_tE) &loc)

Auxiliary method to check that IP address is not invalid (0). 

* **Parameters:**
  **loc** – Locator which IP address is going to be checked. 
* **Returns:**
  true if IP address is defined (not 0). 
* **Returns:**
  false otherwise.
