# IsLocatorValid

### inline bool eprosima::fastdds::rtps::IsLocatorValid(const [Locator_t](Locator_t.md#_CPPv4N8eprosima7fastdds4rtps9Locator_tE) &loc)

Auxiliary method to check that locator kind is not LOCATOR_KIND_INVALID (-1). 

* **Parameters:**
  **loc** – Locator to be checked. 
* **Returns:**
  true if the locator kind is not LOCATOR_KIND_INVALID. 
* **Returns:**
  false otherwise.
