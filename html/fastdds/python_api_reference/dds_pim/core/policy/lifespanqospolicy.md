# LifespanQosPolicy

### *class* fastdds.LifespanQosPolicy

Specifies the maximum duration of validity of the data written by the DataWriter.

Notes: Mutable Qos Policy

#### clear()

Clears the QosPolicy object

#### *property* duration

Period of validity. 
By default, dds::c_TimeInfinite.

#### *property* thisown

The membership flag
