# SampleRejectedStatusKind

### fastdds.NOT_REJECTED

Default value

### fastdds.REJECTED_BY_INSTANCES_LIMIT

Exceeds the max_instance limit

### fastdds.REJECTED_BY_SAMPLES_LIMIT

Exceeds the max_samples limit

### fastdds.REJECTED_BY_SAMPLES_PER_INSTANCE_LIMIT

Exceeds the max_samples_per_instance limit
