# Exceptions

*Fast DDS* provides a [`RpcException`](../../api_reference/dds_pim/rpc/rpcexception.md#_CPPv4N8eprosima7fastdds3dds3rpc12RpcExceptionE) base class for all the exceptions that can be thrown by the RPC API.
It also provides some builtin exceptions, described in the following table:

#### RPC Builtin Exceptions

| Exception                                                                                                                                                | Description                                                                             |
|----------------------------------------------------------------------------------------------------------------------------------------------------------|-----------------------------------------------------------------------------------------|
| [`RpcBrokenPipeException`](../../api_reference/dds_pim/rpc/rpcbrokenpipeexception.md#_CPPv4N8eprosima7fastdds3dds3rpc22RpcBrokenPipeExceptionE)          | Exception thrown by the RPC API when the communication with the remote endpoint breaks. |
| [`RpcFeedCancelledException`](../../api_reference/dds_pim/rpc/rpcfeedcancelledexception.md#_CPPv4N8eprosima7fastdds3dds3rpc25RpcFeedCancelledExceptionE) | Exception thrown by the RPC API when the feed is cancelled.                             |
| [`RpcTimeoutException`](../../api_reference/dds_pim/rpc/rpctimeoutexception.md#_CPPv4N8eprosima7fastdds3dds3rpc19RpcTimeoutExceptionE)                   | Exception thrown by the RPC API when an operation times out.                            |

According to the [RPC over DDS specification](https://www.omg.org/spec/DDS-RPC/1.0/PDF) 7.5.2,
server-side error conditions are communicated back to the client
using error codes, represented by the [`RemoteExceptionCode_t`](../../api_reference/dds_pim/rpc/remoteexceptioncode_t.md#_CPPv4N8eprosima7fastdds3dds3rpc21RemoteExceptionCode_tE) enumeration. *Fast DDS* provides a
[`RpcRemoteException`](../../api_reference/dds_pim/rpc/rpcremoteexception.md#_CPPv4N8eprosima7fastdds3dds3rpc18RpcRemoteExceptionE) subclass that serves as a base class for a set of exceptions that can be thrown by the RPC API
when a server-side error condition occurs.

The following table describes the equivalence between error codes and exceptions:

#### Equivalence between error codes and exceptions

| Error code                    | Description                                                                | Exception                                                                                                                                                      |
|-------------------------------|----------------------------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `REMOTE_EX_UNSUPPORTED`       | Operation is valid but it is unsupported (a.k.a. not implemented).         | [`RemoteUnsupportedError`](../../api_reference/dds_pim/rpc/remoteunsupportederror.md#_CPPv4N8eprosima7fastdds3dds3rpc22RemoteUnsupportedErrorE)                |
| `REMOTE_EX_INVALID_ARGUMENT`  | The value of a parameter passed has an illegal value.                      | [`RemoteInvalidArgumentError`](../../api_reference/dds_pim/rpc/remoteinvalidargumenterror.md#_CPPv4N8eprosima7fastdds3dds3rpc26RemoteInvalidArgumentErrorE)    |
| `REMOTE_EX_OUT_OF_RESOURCES`  | The remote service ran out of resources while processing the request.      | [`RemoteOutOfResourcesError`](../../api_reference/dds_pim/rpc/remoteoutofresourceserror.md#_CPPv4N8eprosima7fastdds3dds3rpc25RemoteOutOfResourcesErrorE)       |
| `REMOTE_EX_UNKNOWN_OPERATION` | The operation called is unknown.                                           | [`RemoteUnknownOperationError`](../../api_reference/dds_pim/rpc/remoteunknownoperationerror.md#_CPPv4N8eprosima7fastdds3dds3rpc27RemoteUnknownOperationErrorE) |
| `REMOTE_EX_UNKNOWN_EXCEPTION` | A generic, unspecified exception was raised by the service implementation. | [`RemoteUnknownExceptionError`](../../api_reference/dds_pim/rpc/remoteunknownexceptionerror.md#_CPPv4N8eprosima7fastdds3dds3rpc27RemoteUnknownExceptionErrorE) |

Finally, user can also define custom exceptions in the IDL interface file
(see [Exceptions](../../../fastddsgen/interfaces/exceptions.md#fastddsgen-interfaces-exceptions)), that can be raised by calling an operation method.
*Fast DDS* provides a [`RpcOperationError`](../../api_reference/dds_pim/rpc/rpcoperationerror.md#_CPPv4N8eprosima7fastdds3dds3rpc17RpcOperationErrorE) subclass that serves as a base class for all these kind of exceptions,
which are generated by *Fast DDS-Gen* tool from the IDL file.
