# Monitor Service

The *Fast DDS* Monitor Service is a feature of Fast DDS that
grants the user the ability to collect data about the entities existing within
a particular [domain](../../dds_layer/domain/domain.md#dds-layer-domain) (i.e [DomainParticipants](../../dds_layer/domain/domainParticipant/domainParticipant.md#dds-layer-domainparticipant), [DataReaders](../../dds_layer/subscriber/dataReader/dataReader.md#dds-layer-subscriber-datareader), [DataWriters](../../dds_layer/publisher/dataWriter/dataWriter.md#dds-layer-publisher-datawriter))
as well as the capability of detecting possible misconfigurations among them.
